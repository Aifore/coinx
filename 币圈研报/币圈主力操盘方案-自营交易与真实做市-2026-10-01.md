# 从主力视角读懂币圈市场：行为动机、证据链与买卖判断

创建于 2026-10-01  
修订于 2026-10-01：按“理解市场行为，辅助自己的买入卖出”重新编写。

> 本文要解决的问题：如果我是拥有较大仓位、资金或执行需求的市场参与者，为什么可能这样交易？这种行为会留下哪些痕迹？我作为观察者，怎样据此决定买入、等待、减仓或退出？  
> 写法：每类行为都拆成“资金处境 → 目的 → 行为逻辑 → 盘面证据 → 其他解释 → 买卖条件 → 判断失效”。  
> 文中价格、仓位和连续行情案例均为教学假设，不是当前行情，不代表已验证的盈利策略。官方机制与数据口径于 2026-10-01 核验。

## 一、这个视角究竟有什么用？

**有用的地方，是理解大资金受到什么约束，以及它的交易需要什么样的对手盘。**

你不需要先证明“这根 K 线是谁画的”，才有资格交易。更重要的是判断：

1. 现在谁更急于成交：买方，还是卖方？
2. 谁在提供对手盘：愿意接货的买方，还是愿意交货的卖方？
3. 花了这么大的成交量，价格究竟推进了多少？
4. 这一轮急迫成交结束后，还有没有新的需求或供给接力？
5. 如果我的解释对，接下来应当看到什么；如果没看到，怎样退出？

例如，同样一段急跌，可能是基本面恶化后持续卖出，也可能是杠杆多头被动平仓。前者的卖压可能不断补充；后者的被迫卖出可能在一段时间后减弱。两者在“跌的时候”可能很像，但在**跌完后的收复能力与再次回落时的承接**上可能出现差别。

因此，本文不把“洗盘、吸筹、派发”当成直接可见的事实，而把它们当作需要盘面继续验证的解释。

**你最终交易的应是已经出现的供需变化，以及承担风险是否划算，而不是对庄家心理的猜测。**

## 二、先理解三条底层原理

### 2.1 大资金首先考虑的是：怎样完成足够数量的交易

如果我是一个想买入大量现货的基金，我可能同时有三个顾虑：

- 一次买得太快，会把后续买入价推高。
- 买得太慢，可能错过信息兑现或价格重估。
- 买到了却卖不掉，账面盈利就不等于能兑现的利润。

所以，分批交易、在市场有人愿意卖出时承接、在成交活跃时完成订单，都可能只是为了平衡**成交成本、完成速度与库存风险**。

反过来，一个已经持有大量资产、希望减仓的参与者，需要足够多的真实买方。上涨、利好公布和市场关注度提高时，买方更愿意主动成交，可能恰好提供减仓窗口。

这解释了两件看似矛盾的事：

- 大资金可能在价格疲弱时买入，因为当时更容易取得数量。
- 大资金也可能在价格上涨时卖出，因为当时更容易完成退出。

**目的：先理解交易需求，再解释价格表现。不能把“价格涨了”直接翻译成“所有大资金都在买”。**

### 2.2 价格取决于急迫成交与可成交深度的互动

每一笔已经成交的买入都有对应卖出，数量相等。“买的钱比卖的钱多，所以涨”不是准确解释。

更准确的过程是：

- 主动买方不断接受卖方报价；卖盘补充不足时，后续成交需要更高价格。
- 主动卖方不断接受买方报价；买盘补充不足时，后续成交需要更低价格。
- 即使主动成交不大，报价撤退或盘口变薄，也可能让下一笔小单引起较大价格变化。
- 即使主动成交很大，如果反方向持续补充可成交挂单，价格也可能走不远。

因此应同时看“有多少成交”和“这些成交推动了多少价格变化”。

| 观察组合 | 首先考虑的机制 | 下一步验证 |
|---|---|---|
| 主动卖出较多，价格下移越来越有限 | 卖单可能被较强买盘承接 | 卖压减弱后，价格能否回升并守住 |
| 主动买入较多，价格上移越来越有限 | 买单可能被持续卖盘承接 | 买盘减弱后，价格是否回落并失守 |
| 成交不大，价格突然大幅上涨 | 卖盘稀薄或撤退，也可能有新信息引发重报价 | 高价能否继续成交，回落时是否有人接 |
| 成交不大，价格突然大幅下跌 | 买盘稀薄或撤退，也可能有新信息引发重报价 | 低价是被迅速收回，还是持续被接受 |

这些是相容的机制，不是单一指标就能证明的因果关系。比较时应固定市场、时间窗和数据口径，结合报价变化；不能把不同波动环境里的两段成交量机械比较。

### 2.3 主力也需要退出，边际价格不等于整仓兑现价

假设某人持有 30,000 枚币，平均成本 1.10，屏幕最新成交价 1.20，看起来浮盈 3,000。

但如果可供退出的买盘是：

| 买价 | 能承接数量 | 卖出所得 |
|---|---:|---:|
| 1.05 | 10,000 | 10,500 |
| 0.95 | 10,000 | 9,500 |
| 0.85 | 10,000 | 8,500 |
| 合计 | 30,000 | 28,500 |

投入成本为 33,000，全部按这个静态盘口卖出会亏损 4,500，尚未计费。

**原理：最后一小笔成交决定的显示价格，并不能保证整仓都卖在同样的位置。目的：理解为什么持仓很大的卖方偏好有持续外部买盘的行情。**

反过来，不要把高位大量成交直接当成健康。它也可能是在完成大规模持仓转移。真正需要观察的是：转移以后，高价还能不能得到新的买方支持。

## 三、“主力”不是一个人：先区分参与者

| 参与者 | 可能的目标 | 可能出现的行为 | 观察时容易误判什么 |
|---|---|---|---|
| 方向基金或大户 | 增减净方向仓位 | 分批买卖、事件前后调仓 | 把所有拆单都当成秘密控盘 |
| 做市商 | 获得价差并控制库存 | 两边报价、调整库存、对冲 | 把撤单或短线卖出都当成看空 |
| 套利或对冲资金 | 赚基差、资金费或降低其他敞口 | 现货买入、期货卖出，或反向操作 | 只看到合约空头就认为在押注下跌 |
| 项目金库、早期持有人 | 筹措现金、兑现或资产配置 | 解锁后转账、转入交易场所、卖出 | 把转账直接等同已经卖出 |
| 被动调仓或集中执行账户 | 完成既定资产配置 | 特定时段持续买卖 | 把执行需求都解释成价格预测 |
| 被强平者、被止损者 | 按规则被动减少风险 | 急迫买回空头或卖出多头 | 认为每一笔大单都有主动战略意图 |

你的观察问题应从“庄家想干什么”进一步收窄成：

**如果这里是有库存的人在卖，它需要什么买盘？如果这里是被迫平仓，订单结束后还剩什么力量？**

身份未知时，先判断交易机制。即使判断出了机制，也不必假定建仓、拉升、派发都是同一个主体完成。

## 四、哪些数据能告诉你什么？

### 4.1 最值得同时看的六组信息

| 数据 | 能帮助回答 | 不能单独证明 |
|---|---|---|
| 价格与关键区间 | 市场是否继续在更高或更低价格成交 | 某个主体的真实成本 |
| 成交量、主动买卖、CVD | 哪一方更主动地接受报价 | 买方或卖方是谁、是否在净建仓 |
| 现货与合约分别的表现 | 行情是否伴随不同市场的交易压力 | 看到先动就证明它是唯一原因 |
| OI，即未平仓合约数量 | 未结清合约规模是增加还是减少 | 多头数量大于空头、入场资金净流向 |
| 资金费、基差、实际强平记录 | 持仓成本、合约相对定价与被动平仓线索 | 下一步必然反转、下一次强平在哪里发生 |
| 订单簿与链上转账 | 可见报价变化及特定资产转移 | 挂单一定成交，转入交易所一定立即卖币 |

### 4.2 CVD：看主动成交，不是看“主力净流入”

在同一数据范围、同一累计起点下：

    CVD = 主动买入成交量的累计值 − 主动卖出成交量的累计值

CVD 上升，表示被统计的主动买入量超过主动卖出量。但主动买入可能来自新增现货买盘、空头平仓、套利或其他目的。

尤其要理解：

- **CVD 上升＋价格横住：**主动买单不断出现，但更高价格推进有限，首先考虑卖方供给在承接这些买单。
- **CVD 下降＋价格横住：**主动卖单不断出现，但更低价格推进有限，首先考虑买方需求在承接这些卖单。

这种承接也可能来自多方参与、对冲或跨市场调整，不能直接识别“同一个庄家”。

现货与永续的 CVD 分开看；明确用基础币数量还是报价币金额累计。不同起点、交易所覆盖、漏报和计算规则会让图形不同。币安成交字段中，买方是 maker 意味着这一笔的主动方是卖方，方向不能读反。[Binance 现货成交流](https://github.com/binance/binance-spot-api-docs/blob/master/web-socket-streams.md)

### 4.3 OI：一张未平仓合约有多空两边

OI 统计尚未结清的合约，按一边计数，不能把多空两边各算一次。新增一张合约同时对应一个多头和一个空头。[CME OI 口径](https://www.cmegroup.com/market-data/volume-open-interest/about.html)

从数量关系看：

| 买方动作 | 卖方动作 | 对 OI 的简化影响 |
|---|---|---|
| 开多 | 开空 | 增加 |
| 平空 | 平多 | 减少 |
| 开多 | 平多 | 不变，持仓转移 |
| 平空 | 开空 | 不变，持仓转移 |

因此，“上涨＋OI 增加”只说明价格上涨期间未平仓规模增加，与新多、新空同时建立相容；不能因此断言只来了新多。

还要检查单位：张数、基础币数量和名义价值不是一回事。若固定数量头寸因价格上涨导致美元计价 OI 增加，这不等于新增同等规模的合约。跨平台、跨合约汇总前必须核验各自定义。

多空“账户数比例”同样不等于多空名义金额比例：很多小账户可以对应少数大账户。它不能推翻每张合约同时存在多空两边的关系。

### 4.4 资金费：持仓成本，不是多空人数统计

正资金费通常是多头向空头付费，负值反过来。它涉及永续与指数价格的相对关系、利息及具体合约规则；结算频率可能调整。[Binance 资金费机制](https://www.binance.com/en/support/faq/detail/360033525031)

正费率偏高可以提示某类持仓成本和拥挤风险，但不能直接推导“马上跌”。如果现货需求持续且卖方不愿提供足够数量，价格仍可能继续涨。

同样，负费率不意味着自动形成底部。下跌中的需求缺失可以持续超过空头付费所形成的压力。

### 4.5 两个很容易让人过度自信的图

**清算热图：**CoinGlass 的相关热图接口说明，它按市场数据和杠杆水平计算潜在清算区域。它是模型输出，不是逐账户真实止损、保证金和强平价的公开清单。[CoinGlass 模型说明](https://docs.coinglass.com/reference/liquidation-aggregate-heatmap-model2)

**订单簿大墙：**显示的是可见挂单，可能改变或撤销。Coinbase 的市场数据规则也明确，不公开交易者身份、未触发止损和冰山单隐藏部分。[Coinbase 公开数据范围](https://www.coinbase.com/legal/trading_rules)

你可以据此设想潜在触发区，但不能推出“主力一定会把价格送到这条线”。

## 五、行为一：横盘吸筹——为什么有钱的人可能不急着买上去？

### 主力处境、目的与逻辑

假设我是希望增加长期现货仓位的大买方。我需要的是足够数量与可以接受的平均成本，不是第一时间获得一根上涨 K 线。

如果价格反复进入某个范围时，总有人愿意出售，我可以逐步承接；一次性急买反而可能把剩余卖盘推到更高价。因此，我可能愿意等待，而不是立即提高报价。

因果链是：

**有增持需求 → 重视数量与成本 → 在已有卖盘中分批承接 → 卖压出现但价格下移有限 → 若可售供给减少、需求仍在，后续上涨更容易。**

这解释了“为什么横住也可能有人买”，但并不意味着所有横盘都是吸筹。

### 看什么证据？

- 相似条件下，主动卖出出现后，价格进一步下移的幅度变小。
- 下沿被测试后能够收回，后续回落仍获得承接。
- 不只是某一笔买墙，而是实际成交后仍能维持价格。
- 逐渐出现更高价格的持续成交，而非长期依赖同一条脆弱支撑。
- 有现货层面的证据配合，而不只是永续短期推升。

### 还可能是什么？

普通区间交易、卖方暂时休息、套利买盘对冲其他市场空头，或者下跌过程中的短暂停顿。

### 对你的买卖有什么用？

**先列入观察，等需求开始表现为可验证的价格推进，再考虑入场。**如果选择更早在区间下沿试仓，理由是风险边界清楚，而不是已经确认庄家吸筹。

若下沿失守且无法重新收复，或原来承接处变成反弹时的卖压，吸筹解释需要降级。不能因为“主力在拿货”就无限补仓。

## 六、行为二：洗盘与假跌破——为什么先跌再涨？

### 先讲清楚“洗盘”这个词的含义

市场通常把上涨前或上涨途中，短期持仓被波动迫使退出、随后价格恢复的过程称为洗盘。

如果一个已持仓的大买方希望继续上涨，它可能希望后续遇到的短期卖出意愿减少。但盘面本身并不能证明有人专门策划了这段下跌。

**短期持仓减轻、杠杆下降，是可能观察到的结果；“庄家故意洗掉散户”是额外的意图判断。**

### 原理：关键是卖出是否可持续

价格穿过显眼低点后，可能触发部分止损和多头强平，形成急迫卖出。若它主要是一次性被动订单，而低价仍有足够买方承接，那么这批卖单释放后，价格可能迅速返回原区间。

因果链：

**跌破参考位置 → 部分风险规则触发 → 卖出短时集中 → 若买方能承接且后续卖压不再补充 → 价格收回 → 再次测试验证承接是否存在。**

但如果下跌来自持续现货抛售或新的负面信息，卖压可能不断补充，所谓“洗盘”就会变成真实下跌。

### 为什么换手有时有利于后续上涨？

原本容易在小幅回撤时卖出的持仓退出后，如果接货者更愿意持有，近期可售供给可能减少。随后相同买入量可以推动更大的价格变化。

**这个链条的必要条件，是新持有人没有立即继续卖出，而且需求仍在。**成交量和 K 线并不能直接证明这些条件；降低价格也可能吸引更多短线交易，甚至制造新的套牢卖压。

### 对你的买卖有什么用？

- 跌破那一刻，不急着把下跌命名为洗盘。
- 先观察是否收回原区域，再观察后续回落是否仍获承接。
- 若要交易，买入依据应是“低价未被持续接受，收复后有支持”，而不是“应该快洗完了”。
- 如果重新跌回失效位置、反弹无法站回，及时按原计划退出。

**有用的买点来自洗盘假设得到验证后的结构，而不是来自猜测庄家愿意忍耐多久。**

## 七、行为三：突破与试盘——为什么越过关键价格还要看后续？

### 处境与目的

一个有增持需求的大参与者可能愿意支付更高价格，原因是信息变好、执行期限临近，或者等待更低价格的机会成本上升。

已经持仓的人也可能愿意在更高价格继续持有，而不是马上出售。这两类行为都会影响突破。

“试盘”可以用来描述市场在某个价格附近试图成交、观察供需响应的过程；但你无法仅凭一次上涨证明有人专门做了试探。

### 原理：突破是跨过旧供给，持续上涨需要新条件

价格越过前高，只说明那一刻旧卖盘被成交、撤退或重报价。要在更高区间保持交易，还需要买方愿意继续接受新价格，且卖方没有马上大规模补充供给。

**突破 → 旧区域供需被暂时打破 → 新价格出现实际成交 → 回落仍有人接 → 突破解释得到加强。**

一笔薄盘口中的急单也能越过前高，但并不保证需求会延续。

### 看什么证据？

- 突破后不是只留下长上影，而是能在更高区间持续成交。
- 新价格附近出现后续买卖，回落未立即重回旧区间。
- 现货、其他主要场所或更多独立数据提供一致线索。
- 如果发生回踩，原供给区附近开始表现出买方承接。
- OI、资金费没有成为唯一支撑理由。

### 对你的买卖有什么用？

预先选择一种方式：提前小仓试探，或等突破后首次有效回落。前者价格可能更好，但需要容忍更多失败；后者少一些猜测，却可能买得更贵或错过不回踩的行情。

“有效”必须事先定义，例如在预定的 15 分钟观察周期收回区间，并在随后回落中不再失守；这只是待验证的规则示例，不是固定根数就能识别真假突破的定律。

若突破后迅速回到旧区间，随后再次接近突破位却遇到卖压，追涨交易的依据减弱，不应反复把失效解释为“主力又在洗”。

## 八、行为四：持续拉升——为什么涨得越快，反而越要区分买盘性质？

### 大资金可能的目的

从持仓者视角，更高价格可以提高账面价值，也可能带来更好的退出条件；从新买方视角，愿意提高成交价格可能是为了及时获得敞口。

但持续上涨并不必须由某个人不断投入资金“维护”。如果卖方不急于出售，普通规模的新增买盘也能推动较大涨幅。

### 原理：至少区分三种上涨

| 上涨类型 | 因果链 | 你要验证什么 |
|---|---|---|
| 有持续现货需求的上涨 | 新买方持续接受较高价格，卖方供给不够 → 成交区间抬升 | 回调后是否还有需求，利好是否仍改善估值 |
| 空头回补推动的上涨 | 价格上涨 → 空头止损或强平买回 → 短时买压增加 | 回补减弱后是否有新的买方接力 |
| 薄盘口中的上涨 | 卖盘稀少或撤退 → 较小成交推动较大涨幅 | 高价是否可成交，退出时是否同样缺买盘 |

这些机制可以同时存在，也可能在同一轮行情里转换。

### 对你的买卖有什么用？

涨幅本身不能回答是否该追。要问的是：**现在买入，赚的是哪一段剩余需求，而不是已经发生的那一段涨幅？**

如果支持上涨的证据持续存在，可以持有或等待风险较清楚的回落；若短时上涨主要与空头回补相伴，等回补潮结束后的承接更有信息价值。

已有仓位时，关注“新增买单很多，但价格越来越难上行”的变化。它可能意味着供给增加，持有逻辑正在从需求主导转向买卖平衡，而不是机械等到价格跌很多才反应。

## 九、行为五：回踩与缩量整理——为什么上涨后不一定要继续涨？

### 处境、目的与逻辑

一段上涨后，早期买方可能获利卖出，短线交易者可能平仓，后来者又不愿在短时高价追买。价格暂时回落或横盘，可以是正常的库存和预期重新匹配。

从仍看好的大买方视角，它可能愿意在较低区域补充需求，但不愿无限承担所有抛售。**因此“有人看好”并不意味着每一根阴线都会被托住。**

若回落中卖方缺乏持续性，而到关键区域后需求恢复，就可能形成继续上涨的条件。

### 缩量到底说明什么？

只说明被统计时段的成交较少。可能是卖出意愿减弱，也可能是买卖双方都不活跃。不能只靠缩量就说“浮筹洗净”。

更有用的是联合观察：

- 价格回落时是否仍在可接受的原结构内。
- 较少成交是否就引起大幅下跌；若是，可能是买盘很薄。
- 到达参考区域后，实际承接是否出现。
- 承接后能否重新推进，而不是勉强停住。

### 对你的买卖有什么用？

若原来上涨的理由未变，回落不破坏结构且出现实际承接，可以寻找比追涨更清楚的失效边界。若跌破参考区域后，反弹一直被卖方压回，就不能继续沿用“健康回踩”的解释。

**买的是需求恢复，不是“已经回调了足够多”。**

## 十、行为六：高位派发——为什么有人一边上涨，一边卖出？

### 主力处境与目的

假设我已经持有较大数量，目标是把资产换成现金。集中向薄弱买盘卖出会明显降低平均退出价格。

当市场乐观、主动买单增多时，我可能更容易逐步卖出。我的卖出不必马上让价格下跌，因为同一时期还有其他人继续买入。

因果链：

**已有较大库存需要退出 → 等待或利用真实买方活跃的时段出售 → 买盘被持续供给承接 → 成交很多但上涨效率下降 → 若新增需求减弱，价格开始下移。**

这解释了“上涨也可能有人在减仓”，并不意味着所有高位横盘都是派发。

### 重点看什么？

- 主动买入或成交量持续出现，但上行推进越来越有限。
- 多次冲高后很快回到区间，无法在更高价格持续成交。
- 原来的回落支撑开始变弱，反弹恢复速度下降。
- 失守后重返原区间失败，原支撑附近出现持续卖出。
- 官方解锁、已识别持有人转账等背景与供给增加相容，但这些背景不能替代实际交易证据。

### 另一种解释

旧卖方确实在出，但新买方把货接住后继续持有，这可能形成高位再积累，后面仍然上涨。因此，“有人卖”不是卖出信号，**卖出以后市场能否继续在高价成交**才更重要。

### 对你的买卖有什么用？

- 空仓者：在高位买入推进效率下降时，降低追涨意愿，等待高价被重新接受或新的回落机会。
- 已持仓者：把保护收益的注意力提高，可按预设规则分批减仓。
- 当高位承接失败、反弹也无法恢复时，退出理由比“猜顶部”更充分。
- 如果后来突破并稳住更高区间，应修正派发假设，不因先前看空而强行解释。

## 十一、行为七：逼空、踩踏与长影线——谁是在被迫成交？

### 11.1 逼空为什么能让上涨加速？

价格上涨后，部分空头的止损或强平条件被触发，买回空头会形成额外买单。如果卖方供给不足，这些订单推动更高价格，可能再触发下一批风险规则。

**上涨 → 部分空头被动买回 → 急迫买压增加 → 若卖盘不足则继续上涨。**

其目的不能统一归给“主力”：被强平者是在减险或被系统平仓；套利者、做市商和现货买方的目的可能完全不同。

价格上涨、数量口径 OI 减少，并出现对应的空头强平记录，能加强“回补在参与推动”的解释，但仍不能证明所有上涨都来自逼空。

**交易意义：**不要仅因资金费很负就买，也不要仅因涨得快就追。等被动买单减弱后，是否仍有需求支持新的价格区间，决定后续解释。

### 11.2 多头踩踏为什么可以跌过基本面似乎合理的位置？

多头止损或强平形成的卖单优先完成风险处置，不一定等待“合理价值”。若买盘同时撤退或变薄，就可能出现价格越跌、被迫卖出越多的反馈。

**下跌 → 多头减仓或强平 → 急迫卖单增加 → 买盘不足时进一步下跌。**

**交易意义：**强平增加既可能出现在恐慌尾声，也可能只是新一轮下跌的开头。仅看到巨额爆仓不能认定见底；还要看价格能否在卖压之后收回、是否停止形成新的低位成交区。

### 11.3 长影线为什么不直接等于反转？

长下影说明价格曾在低处成交，然后反弹；它不保证后面仍有买盘。长上影同理。

更有效的检查是：影线形成后，接下来的回落或反弹是否破坏刚刚建立的承接／供给判断。

实际强平统计也有覆盖限制，不能把某条接口推送的金额直接当作全市场完整强平总额。Binance 使用标记价格及保证金规则触发强平，不能直接用一根最新成交价影线推断全部账户如何被清算。[Binance 强平机制](https://www.binance.com/en/support/faq/detail/360033525271)

例如，Binance 当前 USDⓈ-M 强平流对每个交易对在每 1,000 毫秒窗口内只推送最新一笔强平订单快照；直接累计这条流不是完整强平总量。该产品聚合成交流也有保险基金与 ADL 成交不包含在内的范围限制。因此，“没看到更多强平”不能独自证明被动订单已经结束。[Binance 合约市场数据流](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-usd-s-m-futures/api/ws-streams/market)

## 十二、行为八：利好不涨、利空不跌——为什么消息方向和价格方向相反？

### 原理：价格交易的是“相对已有预期的变化”

若一项利好在公布前已被广泛预期，提前买入的人可能在公布时兑现；此时新增买方未必足以接走原持仓者想卖出的数量。

**利好被提前预期 → 部分资金先买入 → 消息确认未进一步上修预期 → 兑现卖出增加 → 若新增买盘不足，价格不涨或下跌。**

如果消息比原预期更强，或改变的是长期现金流，需求也可能继续增加，不能机械套用“利好落地必跌”。

利空不跌则可能因为预期更差、部分卖出已经发生、低价需求足够，或市场暂时没有完成定价。

### 从主力视角怎么理解？

有早期仓位的人关心“新的买方还愿意为这条消息支付多少”，而不只关心消息标题是否正面。空仓的新买方则要比较现在的价格与事件之后的价值和风险。

### 对你的买卖有什么用？

在事件前记录：市场原本预期什么，当前价格已经反映了什么，以及什么结果会推翻自己。

事件后同时看预期修正和价格响应：

- 好消息出现，但高位买盘持续被承接、价格无法站稳：警惕兑现供给。
- 坏消息出现，出现卖单却无法持续压低，随后收复关键区域：可以观察卖压是否减弱。
- 如果基本面本身明显变坏，短期抗跌也不能单独证明值得长期持有。

**目的：买卖依据从新闻情绪转向预期差和真实承接。**

## 十三、行为九：压单、托单与突然撤墙——盘口为什么容易让人误读？

### 可见行为背后可能有几种完全不同的目的

- 大买单可能是真实需求，也可能只是某种价格下的条件性意愿。
- 大卖单可能是兑现库存，也可能是做市商调整库存。
- 挂单撤销可能因为参考价格变化、风险限制、在其他市场已成交，或订单到期。
- 有些行为也可能带有误导意图，但不能凭一次撤单判定主体和目的。

市场操纵规则确实会区分虚假供需行为，但对观察者来说，**识别一面墙是否值得依赖，比给挂单人贴标签更直接。**[Coinbase 市场诚信规则](https://www.coinbase.com/legal/trading_rules)

### 应观察什么？

| 只看截图时容易想 | 更有用的验证 |
|---|---|
| 买墙很大，价格跌不下去 | 卖单真的打过来时，墙有没有实际承接，随后价格怎样走 |
| 卖墙很大，肯定要跌 | 买单成交后，供给是否持续补充，价格是否仍推不上去 |
| 墙消失，马上要突破 | 墙消失后有没有真实成交和持续报价支持更高价格 |
| 同一位置一直有单，肯定同一主力 | 公开数据通常不能确认交易者身份，先只记录供给反复出现 |

**买卖意义：**不要仅因为看到挂单就入场。实际成交后的价格响应，比挂单大小更可靠；也不能把“有人接住一次”当成无限保护。

## 十四、行为十：巨鲸转账、解锁与现货／合约不同步

### 14.1 转入交易所，为什么值得看但不能直接当卖出？

转入可能增加可交易库存，因此与潜在供给增加有关。但也可能用于托管、保证金、内部迁移或其他安排。

完整观察链应是：

**可核验的持有人与转账 → 接收地址的真实归属 → 是否进入可交易状态 → 是否出现相应卖出压力 → 价格如何响应。**

只能确认转账时，结论就停在“潜在可售供给变化”。不要跨过中间步骤写成“主力已经砸盘”。

解锁同样是从受限资产变为可能流通，不等于所有持有人同时出售；此前的对冲、场外交易及预期定价都可能改变现货冲击。

### 14.2 现货买、合约卖，为什么不一定矛盾？

若某类资金同时买入现货、卖出同币合约，它可能在做风险对冲或获取基差、资金费补偿。看见合约卖单，不代表它的总头寸是看空。

同理，只看到现货主动买入，也不一定代表该参与者希望价格上涨；它可能在其他地方持有空头。

### 14.3 对你的买卖有什么用？

把不同市场的数据分开，再观察它们如何组合：

- 现货持续愿意在更高区域成交，可以支持较持久需求参与的假设，但仍需识别是否只是阶段性套利或执行。
- 永续先大幅波动、OI 和资金费同时变化，现货响应有限时，要特别检查行情对杠杆订单的依赖。
- 领先与滞后需要同一时间轴和可靠时间戳验证；不能看两张更新时间不同的图就确定传导方向。

多个市场同步也可能是套利与共同信息的结果，不能把三个场所的相同涨幅自动算作三批独立新资金。

**目的：识别行情靠什么维持，而不是寻找一张万能“主力资金流”图。**

## 十五、把容易混淆的现象放在一起比较

### 15.1 “洗盘”还是下跌开始？

| 观察维度 | 更支持暂时被动卖出后恢复 | 更支持持续供给占优 |
|---|---|---|
| 跌破之后 | 很快返回原区间 | 在原区间下方持续成交 |
| 回到关键区域 | 再次回落仍有实际承接 | 反弹接近原支撑就遇卖压 |
| 卖出后的价格响应 | 相似条件下，新增卖单更难推进下跌 | 卖单仍能有效推进，或买盘持续撤退 |
| 杠杆线索 | 去杠杆后价格稳定，并有其他需求接力 | 去杠杆后仍持续下跌，现货卖压未缓解 |
| 你的处理 | 条件确认后再试仓，预先定义失效 | 不以“洗盘”作为补仓理由 |

### 15.2 高位再积累还是派发？

| 观察维度 | 更支持高价被接受 | 更支持供给逐渐占优 |
|---|---|---|
| 大量买入后的结果 | 价格最终能向上推进并保持 | 多次投入买量仍无法维持高价 |
| 区间下沿 | 失守后收回，或回落仍有需求 | 反复测试后失守，随后收复失败 |
| 冲高回落 | 回落后较快形成新承接 | 高点难维持，反弹越来越难恢复 |
| 交易意义 | 等更高区间或回落承接验证 | 已持仓者加强保护，空仓者降低追高意愿 |

### 15.3 价格和 OI 的四种组合

| 价格与数量口径 OI | 合理的候选解释 | 需要补什么 | 不能这样下结论 |
|---|---|---|---|
| 价格涨，OI 增 | 新合约建立，买方更积极接受当前报价 | 现货、主动成交、资金费、基差 | “只有新多进场” |
| 价格涨，OI 减 | 平仓净增加，可能有空头回补参与 | 对应强平、现货需求、后续高价承接 | “空头已经全部爆完” |
| 价格跌，OI 增 | 新合约建立，卖方更积极接受当前报价 | 现货压力、对冲背景、资金费 | “庄家确定在开空” |
| 价格跌，OI 减 | 平仓净增加，可能有多头减仓参与 | 实际强平、低价承接、收复能力 | “已经洗完，可以抄底” |

这些表帮助组织假设，不是经回测证明的信号表。没有补充证据时，正确结论可以是“暂时无法区分”。

## 十六、三个连续行情案例：从看到现象到决定买卖

以下均为虚构案例。重点是**在每个时点只使用当时已知的信息**，不能用最后的涨跌倒推前面的故事。

### 案例 A：跌破 100 后收回——怎样交易“需求恢复”？

**背景：**此前价格在 100—110 区间交易。你提前把 100 附近设为观察区域。

| 时点 | 当时看到什么 | 当时合理的解释 | 当时可以做什么 |
|---|---|---|---|
| T1 | 从 102 跌到 97，主动卖出增加 | 卖方急迫，可能是持续下跌，也可能有被动平仓 | 继续观察，不能直接认定洗盘 |
| T2 | OI 数量下降并有多头强平记录；价格重新回到 101 | 去杠杆参与其中，低价暂未被维持 | 更新假设，但还不能排除弱反弹 |
| T3 | 再次接近 100 时出现实际承接，之后恢复到 101 上方 | 收复后的需求有所验证 | 若成本与风险合适，可按事先规则试仓 |
| T4-A | 后续继续保持原区间内交易并向上推进 | 需求恢复解释得到加强 | 持有并按新的价格结构管理风险 |
| T4-B | 跌回 99 下方且无法恢复 | 这笔“收复后继续恢复”的交易依据失效 | 按计划退出，不改口长期吸筹 |

**为什么不在 T1 一跌就买？**因为当时还没有看到卖出是否结束。等 T3，可能付出更高入场价，但少承担一段“下跌究竟会不会停”的猜测。

**为什么也不能保证 T3 会涨？**因为承接可以消失，新信息也可以改变供需。确认提供的是更明确的交易条件，不是保证。

### 案例 B：价格新高、买量很大，却越来越涨不动

**背景：**价格已从 80 涨到 120，你持有盈利仓位。

| 时点 | 当时看到什么 | 推理 | 应对 |
|---|---|---|---|
| T1 | 120 附近买入活跃，价格能短暂到 123 | 需求存在，但不能确定能否维持 | 不因一根新高就追加大仓 |
| T2 | 多次冲到 123—124 后回落，主动买入很多，价格推进有限 | 卖方持续提供数量的假设增强 | 按原规则收紧风险、考虑分批兑现 |
| T3 | 跌破预先定义的 118 支撑区域，反弹到该区域又被卖回 | 原承接未恢复，供给占优证据更明确 | 减仓或退出与此结构相关的交易 |
| 替代发展 | 没有失守，后来在 124 上方持续成交并承接回落 | 高位供给被消化，原派发假设减弱 | 重新评估，不固执猜顶 |

**卖出的目的：**保护已经取得的收益，并退出逐渐失效的需求判断。你不需要证明“主力已经派发完”，也不需要卖在最高点。

### 案例 C：负资金费、急涨、OI 降低——追还是等？

**背景：**某币资金费为负，价格从 50 急涨到 56。

| 观察 | 能支持的解释 | 还不能得出的结论 |
|---|---|---|
| 急涨期间数量口径 OI 减少 | 平仓占优，可能有空头回补 | 所有空头都已退出 |
| 对应空头强平记录增加 | 被动买回参与了行情 | 后面一定继续涨 |
| 急涨后回落，但现货在 54 附近持续承接 | 新需求可能接过部分驱动力 | 54 永远不会失守 |
| 或者：现货承接弱，价格重新回到原区域 | 回补结束后缺乏后续需求的解释加强 | 可以无风险反手做空 |

**买卖逻辑：**如果要做延续，等待回补后的承接验证；如果已经持有，观察新价格区间能否维持。负资金费、OI 下降和强平记录并不是三份完全独立的证据，它们可能都反映同一次去杠杆过程。

## 十七、把观察变成明确的交易计划

### 17.1 先限定你在交易什么

最小版本先研究两种情境：

1. 低价被拒绝后，需求恢复。
2. 更高价格被接受后，回落仍有承接。

选择它们的原因是，入场假设和失效条件相对容易表达。这里不是宣称这两种方式天然盈利；它们仍需用你的真实记录验证。

不要同时做“猜底、追涨、抄回调、赌逼空、猜派发”五套互相冲突的解释，再在亏损后随意切换。

### 17.2 买入前固定五件事

| 必须写下 | 示例 | 目的 |
|---|---|---|
| 事实 | 跌破后收回，后续回落在参考区域有实际承接 | 区分观察与猜测 |
| 主假设 | 原先集中卖压减弱，买方需求恢复 | 明确买入的因果理由 |
| 备选解释 | 只是短暂回补或弱反弹 | 防止只找支持自己的证据 |
| 确认与失效条件 | 在预定时间窗保持区域，跌回并无法收复则失效 | 避免事后移动判断标准 |
| 成本和风险 | 入场、退出、费用、滑点、规模、最迟复核时间 | 让解释转化为有边界的下注 |

时间周期要先固定。可用较大周期确定区间、较小周期观察执行，例如 4 小时结构与 15 分钟确认；这只是分工示例，不是最佳周期结论。不能在 15 分钟依据失效后，临时改成“我看的是周线”。

### 17.3 为什么“看对方向”仍可能不值得买？

假设前面的恢复交易允许在 101 入场，失效退出参考价 99，上方首次明显供给区在 108；预估每枚往返费用和滑点共 0.2。

    计划每枚损失 = 101 − 99 ＋ 0.2 = 2.2
    假设在 108 退出时每枚净收益 = 108 − 101 − 0.2 = 6.8
    示例收益风险比 = 6.8 ÷ 2.2 ≈ 3.09

如果等到 107 才追入，而失效条件仍在 99、下一供给区仍在 108：

    计划每枚损失 = 107 − 99 ＋ 0.2 = 8.2
    同一退出假设下每枚净收益 = 108 − 107 − 0.2 = 0.8
    示例收益风险比 = 0.8 ÷ 8.2 ≈ 0.10

同一个市场解释，不同入场价可能产生完全不同的交易质量。108 只是观察到的潜在供给区，不保证价格会到达，也不保证那里一定反转。

**目的：买卖时机不仅取决于方向，还取决于入场时剩余空间与失效成本。**收益风险比高也不自动等于正期望，还需要实际成功概率、成本与尾部风险的数据。

### 17.4 仓位由“判断错了会怎样”决定

若自行给这笔交易设定的正常计划损失预算为 220，使用上面的 2.2 每枚风险：

    示例数量 = 220 ÷ 2.2 = 100 枚
    示例现货资金占用 = 100 × 101 = 10,100

再根据实际账户可用资金、流动性、其他相关仓位进一步减少数量。

止损价只是触发或计划参考，不保证成交。假如实际每枚总损失达到 5，100 枚就会亏 500。因此需要另算跳空和流动性变差，不把“主力应该守这里”当保护。

### 17.5 卖出依据与买入依据对应

| 原买入理由 | 需要继续看到什么 | 何时减仓或退出 |
|---|---|---|
| 跌破后需求恢复 | 参考区域重新获得承接，并有后续推进 | 再次失守且无法恢复；或到期仍无预期发展 |
| 突破后高价被接受 | 新区间能够维持，回落有需求 | 回到旧区间并持续被接受，反弹恢复失败 |
| 延续上涨 | 新买方能继续推动价格 | 买量增加却推进减弱，承接失守，或已到预定兑现区 |
| 公开事件带来价值重估 | 事件实际改善原来的价值或需求假设 | 假设落空、价格提前充分计价，或供给压过新增需求 |

正常退出不必等待“操盘全过程走完”。如果你交易的是一次短期需求恢复，就不应在失效后改成等待某个完整牛市周期。

## 十八、每天怎么看盘：一页记录就够

### 开始观察前

- 确认交易对、现货／合约、平台、时间周期和数据单位。
- 标出事先重要的成交区间、前高前低和事件时点。
- 写下今天最想验证的一个假设，并给出一个反面解释。
- 对数据缺失标“未取得”，不能把缺失当零。

### 出现显著行为时

按这个顺序记录：

    发生了什么
    → 哪类人可能需要这样交易
    → 他们的目标和约束是什么
    → 为什么会产生这样的订单与价格响应
    → 如果解释正确，下一步应该出现什么
    → 出现什么就说明我错了
    → 当前入场成本、退出条件是否合适

### 一张可复制的观察卡

| 字段 | 内容 |
|---|---|
| 时间与市场 | 日期、平台、交易对、产品、观察周期 |
| 原始事实 | 价格、成交、主动方向、OI、资金费、已知事件；缺什么写什么 |
| 主假设 | 例如：短时被动卖出减弱后，需求恢复 |
| 行为主体候选 | 大买方、获利卖方、做市商、套利者或被动平仓者 |
| 目的与约束 | 想取得数量、兑现库存、降低风险或完成既定订单 |
| 逻辑链 | 目标如何转为订单，订单如何影响成交与价格 |
| 替代解释 | 哪一种不同机制也能解释当前事实 |
| 后续预期 | 在多长时间内，希望看到怎样的承接或价格推进 |
| 失效条件 | 什么事实出现就放弃当前交易解释 |
| 行动 | 等待、试仓、持有、减仓或退出；理由是什么 |
| 结果与复盘 | 当时预测的下一步是否发生，扣费后结果如何 |

### 复盘时最值得检查的三个问题

1. 我是在行情发生前给出了可验证预期，还是发生后才套上“吸筹、洗盘、派发”的词？
2. 同样条件出现却失败的案例，我有没有完整记录？
3. 盈利来自我理解的机制，还是来自市场整体上涨、偶然波动或承担了额外风险？

尽量用未参与制定规则的后续样本检验，保留失败案例。不要为了证明一套故事，反复挑选最符合它的历史截图。

## 十九、最容易让这个视角失效的十种想法

| 容易陷入的说法 | 应改成什么问题 |
|---|---|
| 跌了就是洗盘 | 卖压以后能不能收回，后续有没有承接？ |
| 涨了就是主力拉盘 | 是新增需求、回补，还是盘口变薄？ |
| 主力成本在这里，不可能跌破 | 我怎么知道成本？即使知道，对方有没有其他对冲或退出需求？ |
| 大买墙一定托得住 | 真有卖单到来时，它是否实际成交并继续承接？ |
| CVD 很强就是资金净流入 | 主动买入被谁承接，价格有没有推进？ |
| OI 上升说明主力做多 | 新合约的另一边是谁，是否有对冲背景？ |
| 爆仓很多就是底部 | 被动卖出结束后，仍有没有持续卖压？ |
| 热图上方很亮，一定要去扫 | 模型估计可靠吗，实际供需支持价格到达吗？ |
| 巨鲸转入交易所就是砸盘 | 转账用途和后续成交是否有证据？ |
| 再等等庄家就会拉 | 原来的交易假设是否已经失效，退出条件是什么？ |

你可以用“吸筹、洗盘、派发”帮助组织观察，但不要用这些词豁免止损、扩大仓位或掩盖缺失的数据。
