## 运行脚本

研报中的数据脚本依赖 numpy、matplotlib、plotly，已在 `pyproject.toml` 声明，用 [uv](https://docs.astral.sh/uv/) 运行：

```bash
uv sync
uv run python 币圈研报/资金费完整历史研究/collect_data.py
```

原始数据来自币安、BitMEX 等交易所的公开接口。

币安持仓工具有额外要求：

- 需要已安装并登录**只读**账户的 `binance-cli`，脚本本身不读取也不保存密钥
- 菜单栏工具 `make binance-bar` 仅支持 macOS

```bash
make binance      # 终端输出持仓报告
make binance-bar  # 菜单栏显示今日盈亏
```
