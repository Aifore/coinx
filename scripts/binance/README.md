# 币安只读持仓报告

创建于 2026-09-21

独立于 Coinx 前端的本地报表工具。依赖 Python 3.11+、已安装且已激活只读账户的 `binance-cli`；不需要第三方 Python 包，不读取或输出密钥。

## 运行

在 Coinx 根目录执行：

```bash
make binance
```

报告准备好后会清空交互式终端的当前画面和回滚历史，再输出报告。保存文件或重定向输出时不包含清屏控制字符。等价于 `python3 scripts/binance/binance_report.py`。

同时保存最新报告（覆盖该报告文件）：

```bash
python3 scripts/binance/binance_report.py \
  --output scripts/binance/outputs/binance-report-latest.md
```

输出路径相对于当前工作目录；自定义目录必须先创建。`--timeout 20` 设置每个请求的超时秒数，临时错误最多重试一次，并发上限为 4。

## 菜单栏

```bash
make binance-bar
```

在 Mac 顶部菜单栏显示今日估算盈亏合计（与报告“已覆盖部分合计”同口径），默认每 5 分钟自动刷新，可在菜单“刷新频率”中改为 1/5/15/30/60 分钟，选择会保存，重启后保留。点击后展开“总览”“现货”“合约”三项（总览行右侧为现货与合约的今日盈亏合计，明细表按币种汇总所有账户（现货、币本位与 U 本位合约权益、资金、Simple Earn）的数量、市值与占比，无法拆分币种的交易机器人单列一行，总资产口径同报告的账户总价值），鼠标移到对应项会在右侧展开明细表：首行为汇总，其下各币种按仓位由高到低排序（现货按市值，合约按仓位价值）。现货列出数量、现价、市值、涨幅、今日盈亏；合约列出开仓价、现价、仓位价值、保证金、浮盈、回报率、今日盈亏（U 本位名称省略 USDT 后缀），明细含 U 本位、币本位持仓及币本位抵押币（抵押币只有今日盈亏，其余列为“—”，排最后）；资金费不单列，只计入合约合计的今日盈亏，汇总回报率＝未实现盈亏合计÷保证金合计。各列按实测文字宽度用右对齐制表位对齐；数据列总宽超过 `MAX_SCROLL_WIDTH`（默认 360pt）时可用触控板左右滑动，或直接转动鼠标滚轮（纵向滚动自动换算为横向），首列币种名固定不动。屏幕右侧仍放不下时调小该值。按住 ⌘ 拖动顶部图标可调整位置，重启后保留。现货、U 本位持仓与账户接口全部查询失败（如断网）时，保留上次成功的数据并在菜单顶部注明“以下为 N 分钟前的数据”，顶部数字加 ⚠；个别接口失败则正常显示其余数据。有查询失败时数字后显示 ⚠，菜单中可查看数据缺口。依赖 `uv` 自动安装 `rumps`，进程随终端退出。

## 测试与维护

```bash
python3 -m unittest discover -s scripts/binance -p 'test_*.py' -v
ruff check scripts/binance
ruff format --check scripts/binance
```

`binance_report.py` 包含只读命令白名单、账户/行情采集、Decimal 计算和固定 Markdown 模板；`test_binance_report.py` 覆盖 UTC 日期、做多/做空、保证金口径、逆向合约、分页及失败处理。修改计算口径或字段时同时更新测试。

退出码 0 表示已完成查询及校验；1 表示报告含数据缺口，仍须阅读本次标准输出，不能当作零余额；启动或参数错误可能没有报告，不能用旧文件冒充本次结果。

## 报告边界

- 顶部账户总价值按现货（含锁定）、Simple Earn 活期与定期、资金账户、U 本位和币本位账户权益、交易机器人余额汇总，统一折算 USDT；合约采用各币种 `marginBalance`，不重复加浮盈、保证金或名义价值。终端数字显示柔和绿色，文件保持纯 Markdown。
- 任一账户余额、权益或估值缺失时，总价值显示“未取得”，另列可核实账户小计；钱包总览发现其他未覆盖账户有余额时同样标记不完整。沿用下述忽略币种规则，机器人按总览估值计入，币种明细仍为缺口。
- 今日估算从 UTC 00:00 起算，现货包含 free 与 locked，默认忽略 LDUSDC、EFI、PARA、BTTC。
- 合约开仓均价、未实现盈亏取接口字段；保证金收益率使用 positionInitialMargin，不含挂单保证金。
- 未完整核对日内交易、资金流和费用，估算不等于实际今日盈亏；网格内部收益和未核实的理财收益不纳入合计。
- `outputs/` 含私人账户数据，已加入忽略规则；不得放入 `public/`、`src/` 或网站构建产物。
- 每日北京时间 18:00 的现有 Codex 定时任务调用此脚本并交付标准输出；脚本自身不创建系统定时器，不执行交易。
